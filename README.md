# SQL Data Warehouse Project

Building a modern data warehouse with SQL Server, including ETL processes, data modeling, and analytics.

## Project Overview

This project demonstrates the development of a modern data warehouse using SQL Server.

The project includes:

* Data extraction from ERP and CRM source systems
* Data cleaning and transformation
* Data warehouse development
* Data modeling
* SQL-based analytics

## Data Architecture

The data warehouse follows a layered architecture:

* **Bronze Layer** – Raw data
* **Silver Layer** – Cleaned and transformed data
* **Gold Layer** – Business-ready data for analytics
